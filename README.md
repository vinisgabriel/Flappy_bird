## 📖 Sobre o Jogo

Clone do famoso **Flappy Bird** desenvolvido em **JavaScript puro** com **HTML5 Canvas**. O jogo mantém a jogabilidade clássica e adiciona um **modo moeda secreto** onde você coleta **Bitcoins** para acumular pontos extras!

📱 **Versão Android disponível!** Baixe o APK na seção de downloads.

---

## ✨ Funcionalidades

| Funcionalidade | Descrição |
|----------------|-----------|
| 🎯 **Jogabilidade Clássica** | Pule sobre os canos para marcar pontos |
| 🪙 **Modo Moeda Secreto** | Passe pelo 10º cano e entre em uma fase especial |
| 💰 **Bitcoins** | Colete 10 Bitcoins, cada um vale 10 pontos |
| 🏆 **Sistema de Medalhas** | Bronze, Prata, Ouro e Platina |
| 📊 **Top 10 Scores** | Histórico das melhores pontuações |
| 💾 **Salvamento Local** | Recordes salvos no navegador |
| 🎵 **Efeitos Sonoros** | Sons para cada ação |
| 🌀 **Transição de Íris** | Animação suave entre modos |
| ⚙️ **Menu de Configurações** | Ajuste gravidade, velocidade e pulo |
| 📱 **APK Android** | Versão offline para celular |

## 🎯 Como Jogar

### 🕹️ Controles
- **Desktop:** Clique com o mouse para pular
- **Mobile:** Toque na tela para pular

### 📋 Regras
1. Desvie dos canos para marcar pontos
2. Cada par de canos = **1 ponto**
3. Ao passar pelo **10º cano**, entre no **modo moeda**
4. Colete os **10 Bitcoins** (cada um vale **10 pontos**)
5. Cano de retorno aparece → entre nele para voltar
